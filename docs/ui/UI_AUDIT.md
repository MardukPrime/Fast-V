# UI 覆盖与文字布局审查

审查日期：2026-11-18 · 版本：v0.3 开发线（i18n 落地后）

## 方法

- **静态审查**：脚本 `.task/audit/css_audit.py` 统计全部样式表的颜色字面量、`color-mix` 使用、`var(--accent*)` 引用、浅色主题覆盖、圆角与字号分布；`.task/audit/i18n_audit.py` 校验 `t()` 使用 key 与中英词典的完整性。
- **运行时审查**：以真实构建（`bin/fastv.exe`）加载示范数据，在 1280×800 下逐页截图；覆盖浅色/深色、5 套强调色、底栏布局，以及**中文与英文两种界面语言**。截图位于 `.task/audit-en/`、`.task/accent-check/`。

## 一、主题与强调色覆盖

| 区域 | 浅色 | 深色 | 强调色 | 结论 |
|---|---|---|---|---|
| 应用外壳（标题栏/侧栏/底栏/顶栏） | ✅ | ✅ | ✅ | 全部走 token |
| 概览 Hero / 统计卡 / 流量图 | ✅ | ✅ | ✅ | 含套餐到期警示色 |
| 服务器页（工具条/批量条/表格/标签栏/编辑器） | ✅ | ✅ | ✅ | `--srv-tint*` 已改 accent 变量 |
| 订阅页（统计/表单/卡片/进度条） | ✅ | ✅ | ✅ | 进度条 70/90% 阈值色独立 |
| 路由页（工具条/预设/表格/弹窗） | ✅ | ✅ | ✅ | Type 列加宽避免英文截断 |
| 网络诊断（Hero/事实卡/历史/自检） | ✅ | ✅ | ✅ | 事实标签改为可换行 |
| 日志页（工具条/表格/空态） | ✅ | ✅ | ✅ | 等级色为语义色，不随 accent |
| 设置页（7 个区块、WebDAV、快捷键录制、更新面板） | ✅ | ✅ | ✅ | 全部 token 化 |
| 通用组件（弹窗/开关/按钮/输入框/焦点环） | ✅ | ✅ | ✅ | focus-visible 使用 accent |

静态数据（`styles.css`）：761 处颜色声明中 754 处为字面量，但其中绝大多数是 `:root` token 定义、玻璃白/黑高光与语义色；**159 处 `color-mix`、283 处 `var(--accent*)`、146 条浅色主题覆盖**。四份页面级 CSS（dashboard/servers/subscriptions/routing 等，各 12–15 KB）几乎全部使用 token，剩余字面量仅语义色/玻璃高光。

**残留（非 bug，建议后续统一）**

1. `.dashboard-stat-icon.indigo` 等装饰性色（`#b9c8ff`）与语义色并列，属独立装饰，不随强调色。
2. 浅色主题中性 navy 阴影/内嵌线（`rgba(44,67,90,…)` 等）刻意保持中性，未染强调色。
3. `styles.css` 仍有 184 条 `font-size < 11px` 声明（大量为被后续层覆盖的早期规则）；实际生效层的最小字号已收敛到 9–11px，但 `network-facts` 等微标签仍偏小。
4. 圆角仍有 19 种取值，建议收敛为 8/10/12/16/20 五档。

## 二、文字布局审查

以中/英双语逐页核对"框内文字与边框、行高、截断、对齐"：

| 位置 | 问题 | 处理 |
|---|---|---|
| 概览 · Xray 内核卡 / Hero meta | 未安装时显示后端中文「未安装」，英文界面下中英混排 | 后端 `coreVersion` 不再返回中文占位；前端 Hero 用 i18n 文案兜底 |
| 网络诊断 · 事实卡标签 | 英文 `CLOUDFLARE NODE` 被省略号截断为 `CLOUDFLARE NO...` | 标签允许换行并提升到 9px（`.network-facts span`） |
| 路由表 · TYPE 列 | 固定 100px，英文 `Network protocol` 有贴边风险 | 基础 112px、窄屏 96px |
| 服务器页 · 状态列（80px） | 英文 `Enabled` 接近列宽上限 | 现状不破版；列为后续观察项（可缩短为 On/Off 或加内边距） |
| 订阅卡片 | 英文用量/日期在 2% 进度条行内布局正常 | 无需调整 |
| 日志工具条 | 英文按钮较长，1280px 下仍为单行 | 已验证；<1100px 会换行 |
| 设置页（全部区块展开） | 英文长说明均换行，未见溢出；开关行/按钮未被撑破 | 无需调整 |
| 全局 | 切换语言后，已弹出的成功/错误提示为快照字符串，需下次操作刷新 | 常规 i18n 行为，记录为已知限制 |

同时确认：所有卡片/面板内边距 ≥ 12px，标题与说明行高 ≥ 1.4，表格行内文字与行边界无相切；`node-table`、`routing-table`、订阅卡片在 1100px 窄屏下无横向滚动。

## 三、i18n 完整性

- 中/英词典各 **1058** 条，代码使用 **1034** 个 key，缺失 0、空值 0；未使用的 24 条为路由类型/动作的**动态拼接 key**（`route.type.<value>`），实际有效。
- 覆盖页面：应用外壳（导航/顶栏/底栏/窗口按钮）、概览、服务器（含导入/标签/编辑器弹窗）、订阅、二维码弹窗、路由、网络诊断、日志、设置（含 WebDAV/快捷键录制/更新面板）。
- 语言切换为运行时响应（`setLanguage` + signal），保存后持久化；后端返回的中文错误按设计原样展示。

## 四、已知限制与后续建议

1. 非母语审校：部分英文为直译（如主题卡 "Bright light" 建议改为 "Bright"），建议后续统一润色。
2. 微字号（8–10px）仍存在于少量标签；建议下一轮统一 ≥9px 并收敛圆角取值。
3. 暗色模式的全页截图回归尚未逐页存档（本轮以浅色为主 + 既有深色截图抽查），建议发版前补一轮。
4. 连接级列表受 Xray API 限制，无法实现（已在 Roadmap 注明）。
