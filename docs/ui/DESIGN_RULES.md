# FastV UI 设计规则

| 项目 | 内容 |
|---|---|
| 文档版本 | v0.1 |
| 状态 | UI 基线 |
| 适用端 | Wails v3 桌面客户端 |
| 前端 | SolidJS + TypeScript |
| 视觉方向 | 液态玻璃、深色优先、低干扰、信息密度高、桌面原生感 |
| 最小窗口 | 960 × 640 |
| 默认窗口 | 1280 × 800 |

---

## 1. 设计目标

FastV 是代理客户端，不是展示型网站。UI 的首要目标是让用户快速完成以下操作：

1. 看清当前代理是否运行。
2. 选择正确的节点。
3. 快速导入和更新订阅。
4. 看懂路由规则和节点状态。
5. 在出错时知道发生了什么、下一步怎么做。

### 1.1 设计原则

- 状态优先：代理状态、当前节点、系统代理状态必须始终可见。
- 少弹窗：普通保存、切换节点不弹窗；只有破坏性操作和需要输入的操作才弹窗。
- 一屏完成：服务器页的主流程不跳转页面。
- 可撤销：单条删除优先提供撤销，而不是每次确认。
- 信息分层：常用操作直接展示，高级配置折叠到高级模式。
- 性能可见：大列表、日志、流量图表必须保持流畅。
- 错误可行动：错误提示要告诉用户发生了什么，以及可以做什么。
- 液态玻璃：使用低饱和磨砂层、细边框高光和柔和阴影建立深度，不使用霓虹渐变。
- 去模板感：避免大面积营销卡片、过强渐变和装饰性动画，保持桌面工具的专业感。

## 2. 整体布局

```text
┌────────────────────────────────────────────────────────────┐
│ 顶部状态区：当前节点 / 代理状态 / 系统代理 / 流量           │
├──────────────┬─────────────────────────────────────────────┤
│ 侧边导航      │ 页面标题 + 页面级操作                        │
│              │                                             │
│ 概览          │ 主内容区                                    │
│ 服务器        │                                             │
│ 订阅          │                                             │
│ 路由          │                                             │
│ 测速          │                                             │
│ 日志          │                                             │
│ 设置          │                                             │
├──────────────┴─────────────────────────────────────────────┤
│ 底部状态栏：内核版本 / 代理模式 / 上传 / 下载 / 延迟         │
└────────────────────────────────────────────────────────────┘
```

### 2.1 尺寸规则

| 元素 | 尺寸 |
|---|---|
| 左侧导航宽度 | 236px |
| 顶部栏高度 | 64px |
| 底部状态栏高度 | 32px |
| 内容区左右内边距 | 32-36px |
| 内容区最大宽度 | 1440px |
| 最小窗口 | 960 × 640 |
| 默认窗口 | 1280 × 800 |

### 2.2 导航规则

- 左侧导航固定，不随页面滚动。
- 当前页面使用高亮背景和左侧强调线。
- 导航项顺序固定：概览、服务器、订阅、路由、测速、日志、设置。
- 图标可选，但文字必须始终显示。
- 导航项不使用大图标卡片，不使用多层折叠导航。
- 设置页面内部使用二级标签页，不增加左侧三级导航。

## 3. 视觉规范

### 3.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--bg-app` | `#0f1219` | 应用背景 |
| `--bg-sidebar` | `rgba(12,15,22,0.72)` | 侧边栏 |
| `--bg-surface` | `rgba(17,24,39,0.56)` | 卡片、面板 |
| `--bg-elevated` | `#151b26` | 弹窗、下拉菜单 |
| `--border-subtle` | `rgba(148,163,184,0.10)` | 普通边框 |
| `--border-strong` | `rgba(148,163,184,0.20)` | 强调边框 |
| `--text-primary` | `#e8edf6` | 主文本 |
| `--text-secondary` | `#94a3b8` | 次要文本 |
| `--text-muted` | `#64748b` | 辅助文本 |
| `--accent` | `#38bdf8` | 主操作、选中、运行状态 |
| `--accent-2` | `#818cf8` | 渐变和次要强调 |
| `--success` | `#22c55e` | 可用、成功 |
| `--warning` | `#f59e0b` | 警告、延迟较高 |
| `--danger` | `#ef4444` | 错误、删除、阻断 |
| `--info` | `#38bdf8` | 信息提示 |

规则：

- 主色只用于主操作和关键状态，不要每个按钮都用主色。
- 红色只用于错误、危险操作和阻断规则。
- 绿色只表示成功或可用，不用于普通装饰。
- 颜色不能作为唯一状态表达，必须配合图标或文字。
- 支持浅色主题时，颜色必须通过 CSS Variables 覆盖，不在组件内硬编码。

### 3.2 字体

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 28px | 700 | 页面主标题 |
| 区块标题 | 18-20px | 600 | 卡片标题 |
| 正文 | 14px | 400 | 常规文本 |
| 表格正文 | 13px | 400 | 高密度列表 |
| 辅助文本 | 12px | 400 | 说明、时间、状态 |
| 标签 | 11px | 500 | 协议、状态、分类 |

字体栈：

```css
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
"Segoe UI", sans-serif
```

规则：

- 正文不使用小于 12px 的字号。
- 数字使用等宽或表格数字特性，避免延迟和流量数字跳动。
- 标签使用大写或小型大写字母风格时，必须保证可读性。

### 3.3 间距

使用 4px 基准：

```text
4, 8, 12, 16, 20, 24, 32, 40, 48
```

规则：

- 页面区块间距 24px。
- 卡片内边距 20-24px。
- 表单字段间距 16px。
- 表格工具栏与表格间距 12px。
- 不要使用 5、7、13 这类无规律的间距。

### 3.4 圆角和阴影

| 元素 | 圆角 |
|---|---|
| 按钮 | 8-10px |
| 输入框 | 8px |
| 卡片 | 14-16px |
| 弹窗 | 16-18px |
| 标签 | 999px |

阴影只用于浮层和模态框：

```css
box-shadow: 0 16px 48px rgba(0, 0, 0, 0.24);
```

不要在普通卡片上使用大面积阴影，不要使用持续变化的发光动画。

## 4. 组件规则

### 4.1 按钮

| 类型 | 用途 |
|---|---|
| Primary | 页面唯一主操作，例如启动代理、保存 |
| Secondary | 次要操作，例如取消、导入 |
| Ghost | 工具栏、表格行内操作 |
| Danger | 删除、清空日志、恢复默认 |

规则：

- 一个页面最多一个 Primary 按钮。
- 图标按钮必须有 tooltip 或 aria-label。
- 按钮加载中必须禁用并显示进度状态。
- 危险操作按钮不能和普通保存按钮相邻且无间距。
- 按钮文字使用动词：启动、停止、导入、更新、删除。

### 4.2 输入框和表单

- 输入框高度 32-36px。
- 表单标签在输入框上方，不使用纯 placeholder 代替标签。
- 必填字段用星号或文字标记。
- 校验在 blur 或提交时触发，不在每次按键时弹错。
- 错误信息显示在字段下方，并说明如何修复。
- 高级字段折叠到高级设置，默认不展开。
- 保存按钮固定在表单底部，不随内容滚动消失。

### 4.3 表格

服务器列表、订阅列表、日志列表都必须支持虚拟滚动。

| 元素 | 规则 |
|---|---|
| 表头 | 固定，不随内容滚动 |
| 行高 | 固定 44-48px |
| 选中 | 整行高亮，支持多选 |
| 行操作 | 右键菜单 + 行尾更多按钮 |
| 空状态 | 图标 + 说明 + 主操作按钮 |
| 加载 | 骨架屏，不用整页 spinner |
| 排序 | 表头点击排序，当前排序有明确标识 |

表格列建议：

```text
选择 | 名称 | 协议 | 地址 | 延迟 | 状态 | 订阅分组 | 操作
```

### 4.4 状态和标签

节点状态：

```text
运行中  绿色 + 圆点
已停止  灰色 + 圆点
启动中  黄色 + 加载图标
错误    红色 + 错误图标
```

延迟：

```text
< 100ms   绿色
100-300ms 黄色
> 300ms   橙色或红色
超时      红色文字
未测试    灰色
```

协议标签使用中性色背景，不要给每种协议分配高饱和颜色，避免视觉噪音。

### 4.5 弹窗

| 宽度 | 用途 |
|---|---|
| 420px | 简单确认、重命名 |
| 560px | 节点编辑、订阅编辑 |
| 720px | 路由规则编辑、复杂配置 |

规则：

- 弹窗标题说明操作对象。
- 底部按钮右对齐：取消在左，确认在右。
- 危险确认使用红色主按钮。
- 弹窗打开时焦点进入第一个可操作元素。
- Esc 关闭普通弹窗；有未保存修改时先确认。
- 不要在弹窗里再打开弹窗，使用抽屉或分步表单代替。

### 4.6 Toast 和通知

- 普通成功提示 2-3 秒自动消失。
- 错误提示不自动消失，必须手动关闭或提供操作。
- 单条删除成功后提供撤销按钮。
- 同一类错误不要连续弹出多个 Toast，合并成一个。
- 系统通知只用于代理启动失败、订阅更新完成、需要用户处理的错误。

## 5. 页面规则

### 5.1 概览

必须显示：

- 当前节点名称
- 代理运行状态
- 系统代理状态
- 当前模式：直连、全局、规则
- 最近 5-10 分钟流量图
- 快速操作：启动/停止、切换节点、更新订阅

不要放大量营销式卡片。概览页只放状态和快捷操作。

### 5.2 服务器

页面结构：

```text
工具栏：搜索 | 订阅筛选 | 协议筛选 | 导入 | 添加 | 测速 | 更多
表格：节点列表
底部：已选数量 | 批量操作
```

规则：

- 单击行选中，双击启动或编辑，行为必须一致。
- 启动中的节点不能重复点击启动。
- 批量删除必须确认。
- 单条删除优先使用撤销 Toast。
- 延迟测试结果只更新对应行，不整表刷新。
- 订阅更新后保留用户排序和自定义名称。

### 5.3 订阅

- 显示订阅名称、域名、节点数量、最近更新时间、下次更新时间。
- 更新失败显示 last_error，不隐藏旧节点。
- 更新中显示进度，不阻塞其他页面。
- 删除订阅必须确认，并说明其节点会如何处理。
- 支持手动更新全部。

### 5.4 测速

- 显示总进度、已完成数量、失败数量。
- 支持取消。
- 结果按延迟或速度排序。
- 测速过程中不禁用整个应用，只禁用会冲突的操作。
- 测速失败的原因要分类：超时、DNS、TLS、认证失败、内核错误。

### 5.5 日志

- 虚拟滚动。
- 支持级别过滤：debug、info、warning、error。
- 支持搜索和清空。
- 自动滚动到底部，用户可以暂停。
- 日志行显示时间、级别、模块、消息。
- 错误行可展开查看详情。
- 敏感字段必须脱敏显示。

### 5.6 设置

分组：

```text
通用
代理
订阅
路由与 DNS
内核
外观
高级
关于
```

规则：

- 修改后立即生效的设置使用开关或选择器。
- 需要重启内核的设置必须明确提示。
- 恢复默认必须二次确认。
- 不在设置页放临时性错误信息，错误通过 Toast 或字段提示展示。

## 6. 路由规则编辑器

路由规则是 FastV 最容易变复杂的界面，必须单独设计。

### 6.1 页面结构

```text
工具栏：新增规则 | 导入 | 导出 | 预览配置 | 校验
规则列表：
  [拖拽] 规则名称 | 条件摘要 | 动作 | 启用开关 | 更多
底部：规则顺序说明 + 未保存状态
```

### 6.2 规则卡片

每条规则显示：

- 拖拽排序手柄
- 启用开关
- 规则名称
- 条件摘要，例如 `domain:google.com + tcp`
- 动作标签：代理、直连、阻断
- 更多菜单：编辑、复制、删除

规则默认折叠，点击展开编辑。

### 6.3 规则编辑表单

字段分组：

```text
基础：名称、启用、动作
匹配条件：域名、IP、端口、网络、入站、协议、进程
目标：代理、直连、阻断、指定 outbound
高级：排除条件、规则标签
```

规则：

- 一个规则至少有一个匹配条件。
- 动作必须明确选择。
- 规则顺序可拖拽调整。
- 保存前显示生成的 Xray 规则预览。
- 不允许在前端直接编辑原始 JSON。
- 高级模式可以查看 JSON，但必须只读。

### 6.4 规则校验

必须阻止保存的情况：

- 没有任何匹配条件。
- 动作缺失。
- 端口格式错误。
- 域名或 IP 列表为空。
- 同时指定 outboundTag 和 balancerTag。
- 使用当前版本不支持的传输或规则字段。

必须警告但不阻止的情况：

- 规则永远不会命中。
- 规则被前面的规则完全覆盖。
- 使用了平台相关字段，例如 process。
- 使用了未安装的 Geo 分类。

### 6.5 规则预览

预览面板显示：

- 生成的 Xray routing rules JSON。
- 规则顺序编号。
- 预计命中的流量类型。
- 明显冲突提示。

预览只读，不提供直接编辑。

## 7. 交互和快捷键

### 7.1 全局快捷键

```text
Ctrl/Cmd + K     打开命令面板或搜索
Ctrl/Cmd + F     当前页面搜索
Ctrl/Cmd + Enter 启动/停止代理
Esc              关闭弹窗或退出编辑
Delete           删除选中项，需确认或撤销
F5               刷新当前列表
```

规则：

- 快捷键不能覆盖系统输入法快捷键。
- 输入框聚焦时，Delete 和 Ctrl+F 不触发全局行为。
- 所有快捷键都应在设置页可查看。

### 7.2 焦点和键盘导航

- 所有可操作元素必须可 Tab 聚焦。
- 焦点环不能被移除，必须可见。
- 表格支持上下键选择行。
- 弹窗打开后焦点锁定在弹窗内。
- 关闭弹窗后焦点返回触发按钮。

### 7.3 危险操作

危险操作包括：

- 删除节点或订阅
- 清空日志
- 恢复默认设置
- 删除路由规则
- 卸载内核

规则：

- 批量删除必须确认。
- 单条删除可以用撤销 Toast。
- 确认文案必须说明后果。
- 不使用无信息量的确认提示。

---

## 8. 状态设计

每个页面必须覆盖：

```text
Loading
Empty
Ready
Error
Disabled
```

规则：

- Loading 使用骨架屏或局部加载状态。
- Empty 状态必须有下一步操作。
- Error 状态必须有重试按钮和错误摘要。
- Disabled 状态必须说明原因，例如请先启动代理。
- 不要用空白页面表示加载失败。

---

## 9. 可访问性

- 文本与背景对比度达到 WCAG AA。
- 状态不能只靠颜色表达。
- 图标按钮必须有 aria-label。
- 表单控件必须有关联 label。
- 错误信息通过 aria-live 通知。
- 支持 125% 和 150% Windows 缩放。
- 不使用只有 hover 才能发现的关键操作。
- 动画尊重 `prefers-reduced-motion`。

---

## 10. 性能规则

- 服务器列表、订阅列表、日志列表使用虚拟滚动。
- 日志批量推送，不逐行触发渲染。
- 流量图每秒更新一次，使用 Canvas 或 uPlot。
- 不频繁整体替换大数组，按 ID 更新单行。
- 页面按路由懒加载。
- 不使用大面积模糊、持续动画和复杂阴影。
- 表格行高固定，避免动态高度导致虚拟滚动抖动。
- 10000 个节点时滚动仍应保持流畅。

---

## 11. 文案规则

- 使用用户能理解的语言，不直接展示 Xray 内部字段名。
- 错误提示包含：发生了什么、影响是什么、可以怎么做。
- 按钮文字使用动词，不使用模糊的确定或提交。
- 中英文文案统一由 i18n 管理。
- 技术字段名在高级模式中保留英文，并提供中文说明。
- 不在 UI 中展示 UUID、密码、私钥和完整订阅 URL。

错误示例：

```text
错误：本地端口 10808 已被占用。
影响：代理无法启动。
操作：更换端口，或关闭占用该端口的程序。
```

---

## 12. SolidJS 实现约定

- 基础组件基于 Kobalte，不引入重型全量组件库。
- 表格和虚拟列表使用 TanStack Solid Table + Virtual。
- 流量图使用 uPlot 或 Canvas。
- 全局状态使用 Solid signals/store，不整体复制大数组。
- 事件订阅在页面卸载时取消。
- 组件样式使用 CSS Variables 和 UnoCSS/Tailwind 工具类。
- 主题切换只切换根节点 class 或 data 属性。
- 不在组件内写 Xray 配置生成逻辑。

---

## 13. UI 验收清单

- [ ] 所有页面都有 Loading、Empty、Error 状态。
- [ ] 代理状态和系统代理状态始终可见。
- [ ] 10000 节点列表滚动流畅。
- [ ] 日志每秒 2000 行不阻塞 UI。
- [ ] 单条删除有撤销，批量删除有确认。
- [ ] 路由规则可拖拽排序，并显示校验结果。
- [ ] 所有图标按钮有 tooltip 或 aria-label。
- [ ] 125% 和 150% 缩放下布局不重叠。
