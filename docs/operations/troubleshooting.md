# 故障排查

## 代理无法启动

1. 检查 xray.exe 是否存在。
2. 执行 `xray -test -config` 查看配置错误。
3. 检查本地端口是否被占用。
4. 查看 `logs/` 下的应用日志和核心日志。
5. 检查防火墙或安全软件是否拦截。

## 系统代理未恢复

1. 检查 `%APPDATA%\FastV\proxy_backup.json`。
2. 在设置页手动点击恢复系统代理。
3. 检查注册表 Internet Settings 当前值。
4. 如果用户手动修改过代理，应用不会盲目覆盖。

## 订阅更新失败

1. 检查网络和订阅 URL。
2. 查看订阅 last_error。
3. 检查响应是否为 Base64 或支持格式。
4. 单条链接失败不会影响其他节点。

## 存在孤儿内核进程

1. 检查 Job Object 是否创建成功。
2. 查看应用是否被强制结束。
3. 手动结束 xray.exe 并重启应用。
4. 收集日志后提交问题。
