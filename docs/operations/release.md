# 发布说明

## 发布步骤

1. 更新版本号和 CHANGELOG。
2. 运行全部测试和配置校验。
3. 执行 `wails3 build`。
4. 下载并校验固定版本 Xray-core。
5. 收集 Geo 数据、LICENSE 和第三方声明。
6. 使用 Inno Setup 或 NSIS 生成安装包。
7. 对 exe 和安装包进行代码签名。
8. 生成 SHA-256 校验文件。
9. 在 Windows 10/11 虚拟机执行冒烟测试。
10. 发布安装包、校验值和更新日志。

## 版本策略

- 应用版本：语义化版本。
- 核心版本：单独记录，不与应用版本混用。
- 数据库 schema 版本：通过 migration 管理。
- 配置文件版本：设置中记录 schemaVersion。

## 回滚

- 保留上一个稳定版本安装包。
- 数据库 migration 必须提供向前兼容策略。
- 核心升级失败时允许回退到内置版本。
