## 1. 安装与系统要求

### 1.1 系统要求

| 平台 | 要求 |
|---|---|
| Windows | Windows 10 / 11 x64；需要 Microsoft Edge WebView2 Runtime |
| macOS | macOS 11 或更新版本；Apple Silicon（arm64）或 Intel（amd64） |
| Linux | x64 或 arm64；需要 GTK3 与 WebKitGTK 4.1（例如 Debian/Ubuntu 的 `libgtk-3-0`、`libwebkit2gtk-4.1-0`） |

通用要求：

- 需要 Xray-core 作为代理内核。FastV 会自动检测本地内核；未安装时可在 **设置 → 内核设置** 中检查并下载。
- TUN 模式仅在 Windows 上提供，并且需要管理员权限与 `wintun.dll`（见 [3.3 TUN 模式](#33-tun-模式)）。

### 1.2 Windows：安装包与便携版

发布页为 <https://github.com/MardukPrime/Fast-V/releases>，同一页面提供 `SHA256SUMS.txt` 用于完整性校验。

- **安装包**：`FastV-<version>-windows-amd64-setup.exe`
  - 双击按向导安装，安装过程需要管理员权限；
  - 默认安装到 `C:\Program Files\FastV`，并创建桌面快捷方式、开始菜单项与卸载入口；
  - 安装包只复制程序文件，不会覆盖或删除订阅、节点与设置等用户数据。
- **便携版**：`FastV-<version>-windows-amd64.zip`
  - 解压后运行其中的 `Fast-V.exe` 即可，无需安装；
  - 升级时用新版本文件替换旧文件即可，用户数据保存在数据目录中（见 [8.5 数据与文件位置](#85-数据与文件位置)）。
- 若启动后窗口空白或提示缺少 WebView2，请先安装 Microsoft Edge WebView2 Runtime（见 [FAQ Q20](product/FAQ.md#q20-windows-启动后白屏或提示缺少-webview2)）。

### 1.3 macOS

- 下载 `FastV-<version>-macos-arm64.zip`（Apple Silicon）或 `FastV-<version>-macos-amd64.zip`（Intel），解压得到 `FastV.app`，拖入「应用程序」。
- 当前构建未签名、未公证：首次启动请**右键点击 `FastV.app` → 打开**，在系统提示中确认打开；之后可正常双击启动。
- 订阅、节点、路由、网络诊断、WebDAV 等核心功能可用；Windows 专属能力（系统代理/PAC/TUN、开机自启、全局快捷键、应用内更新、托盘菜单）暂不提供，详见 [README 的平台说明](../README.md)。

### 1.4 Linux

- **deb 安装包**（推荐 Debian / Ubuntu）：

  ```bash
  sudo apt install ./FastV-<version>-linux-amd64.deb
  ```

  安装到 `/opt/fastv`，同时提供 `/usr/bin/fastv` 命令、桌面入口，并声明 GTK3 / WebKitGTK 4.1 依赖。卸载使用 `sudo apt remove fastv`。

- **tar.gz 便携包**：解压后运行其中的 `FastV`。若文件没有执行权限：

  ```bash
  chmod +x FastV
  ./FastV
  ```

- **AppImage（仅 x86_64）**：下载 `FastV-<version>-linux-amd64.AppImage`，赋予执行权限后直接运行：

  ```bash
  chmod +x FastV-<version>-linux-amd64.AppImage
  ./FastV-<version>-linux-amd64.AppImage
  ```

  AppImage 同样依赖系统 GTK3 与 WebKitGTK 4.1；首次运行可在文件管理器中右键「属性 → 权限 → 允许作为程序执行」。

- 依赖：GTK3 与 WebKitGTK 4.1。Debian / Ubuntu 可执行：

  ```bash
  sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
  ```

  其他发行版请安装名称对应的 GTK3 / WebKitGTK 4.1 包。

### 1.5 首次启动

1. 首次启动会显示三步引导：三种代理模式、导入订阅或节点、配置快照/网络救援/诊断报告等保障能力。可点击「跳过」，引导只显示一次。
2. 若尚未安装 Xray-core，界面会提示未安装：进入 **设置 → 内核设置**，点击「检查更新」或「下载最新版」安装内核；应用也会自动检测本地已有的 Xray-core。
3. 首次运行会创建数据目录（路径可在 **设置 → 应用信息 → 数据目录** 查看）。

## 2. 快速开始

最短上手流程：添加订阅 → 选择节点 → 启动代理 → 测试连通性。

### 2.1 界面导航

| 页面 | 用途 |
|---|---|
| 概览 | 代理状态、当前节点、订阅/节点/套餐/内核摘要、启动与停止、代理测试、最近 7 天流量 |
| 服务器 | 节点列表、搜索筛选、导入节点、收藏与标签、分组、测速、批量操作、编辑节点 |
| 订阅 | 添加与更新订阅、套餐流量与到期、订阅二维码、每个订阅的自动更新设置 |
| 路由 | 规则编辑与排序、规则预设、JSON 导入导出、规则集订阅、规则调试器 |
| 网络诊断 | 出口 IP 与网络质量、延迟历史、一键自检、网络救援、DNS 审计、TUN 自检、诊断报告导出 |
| 日志 | Xray 实时运行日志，支持搜索、等级筛选、暂停、导出与清空 |
| 设置 | 客户端设置、内核设置、智能选路、流量统计、系统集成、备份与恢复、应用信息 |

### 2.2 导入订阅或节点

**方式一：订阅地址**

1. 打开 **订阅** 页，在「添加订阅」中填写名称（可选）与订阅地址。订阅地址必须以 `http://` 或 `https://` 开头。
2. 点击「添加订阅」。FastV 会立即拉取并解析一次，成功后节点出现在 **服务器** 页。
3. 订阅内容支持：分享链接、Base64 编码的订阅内容、Clash / Clash.Meta YAML（支持 VMess、VLESS、Trojan、Shadowsocks，其他协议类型会被逐条跳过并说明原因）。

**方式二：分享链接 / 手动导入**

1. 打开 **服务器** 页，点击「导入节点」。
2. 粘贴一行或多行分享链接（`vmess://`、`vless://`、`trojan://`、`ss://`），也可以粘贴整段 Base64 编码的订阅内容；支持「从剪贴板粘贴」。
3. 点击「导入」。弹窗会显示成功、跳过（重复链接）与错误条数；手动导入的节点在列表中标记为「手动」。

订阅卡片上的「二维码」可扫码导入到其他设备或客户端；节点行内的二维码按钮可查看并复制单节点分享链接。

### 2.3 选择节点并启动代理

1. 在 **服务器** 页点击某个节点，或使用顶部/工具栏的「快速切换节点」，将其设为当前节点。当前节点所在行会显示标记。
2. 在 **概览** 页点击「启动代理」（底栏的启动按钮效果相同）。
3. 启动后概览页会显示本地入站地址（默认 `127.0.0.1:10808`）与运行时长。点击「测试」可用代理访问「代理测试地址」（默认 `https://www.gstatic.com/generate_204`），确认代理链路可用。
4. 需要确认出口 IP 时，打开 **网络诊断** 页运行检测。

切换当前节点时，如果代理正在运行，FastV 会自动重启内核使新节点生效。

### 2.4 代理模式

顶部栏提供三种代理模式，点击即可切换：

| 模式 | 行为 |
|---|---|
| 规则 | 默认模式。命中路由规则时按规则动作处理，未命中的流量走代理 |
| 全局 | 未命中路由规则的流量都经由当前节点转发；已启用的规则仍会先参与匹配 |
| 直连 | 未命中路由规则的流量都不经过代理节点；已启用的规则仍会先参与匹配 |

修改代理模式会保存设置；如果代理正在运行，FastV 会自动重启代理使新模式生效。托盘菜单、**设置 → 客户端设置 → 默认代理模式** 与全局快捷键（`Ctrl+Shift+M`）也可以切换模式。

### 2.5 让其他程序使用代理

- Windows 默认会在启动代理时自动设置系统代理（见 [3.1 Windows 系统代理](#31-windows-系统代理)），浏览器等遵循系统代理的程序无需额外配置。
- 如果关闭了系统代理，或程序只支持手动配置，可在程序中将代理设置为 `127.0.0.1:10808`（SOCKS/HTTP，端口可在设置中修改）。
- 需要让同网段设备使用时，开启「允许局域网连接」并配置入站认证（见 [3.4 局域网共享与入站认证](#34-局域网共享与入站认证)）。

## 3. 网络接管

网络接管能力位于 **设置 → 客户端设置 → 网络接管**，决定 FastV 如何把系统流量交给本地代理。以下系统级能力目前仅在 Windows 上提供。

### 3.1 Windows 系统代理

「Windows 系统代理」有三种模式：

| 模式 | 说明 |
|---|---|
| 关闭 | 不修改 Windows 系统代理，仅保留本地 SOCKS/HTTP 入站 |
| 系统代理 | 启动代理时把 WinINet 系统代理指向 `127.0.0.1:<本地端口>`，停止代理或退出 FastV 时恢复原设置 |
| PAC 智能分流 | 使用本地生成的 `fastv.pac` 自动决定直连或走代理（见 3.2） |

- 系统代理模式下，FastV 会同时设置代理例外（本地地址与常见私有网段直连），停止代理、启动失败或退出应用时都会恢复原有代理设置。
- 若设置系统代理失败（例如注册表被安全软件拦截），代理仍会继续运行，并在日志页写入警告；此时可改用 TUN 模式或手动配置代理。
- 开启 TUN 模式时会自动跳过系统代理设置。

### 3.2 PAC 智能分流

PAC 模式由 FastV 生成本地脚本 `<数据目录>/pac/fastv.pac`，并把 Windows 的自动代理配置（AutoConfigURL）指向它：

- 私有地址、`localhost`、`127.*`、`10.*`、`192.168.*`、`172.16.*`～`172.31.*`、`.local` 等直接连接；
- 其余请求走本地代理。

注意事项：

- 仅 Windows 支持；保存设置后需要重启代理才会生效。
- 停止代理或退出应用时恢复原有自动代理配置，并删除生成的 PAC 文件。
- 切换模式后如果行为未变化，先停止再启动一次代理。

### 3.3 TUN 模式

TUN 模式通过虚拟网卡接管系统流量，适合不遵循系统代理的程序。启用条件：

- Windows 10 / 11；
- 以管理员身份运行 FastV（保存设置或启动代理时 FastV 会请求 UAC 提权）；
- Xray 内核可用，且 `wintun.dll` 与 `xray.exe` 位于同一目录（通常是 `<数据目录>\cores\xray\`）。

启用后 FastV 会自动配置 TUN 地址与系统路由，并在停止代理或退出时清理路由；TUN 模式可与本地 SOCKS/HTTP 入站同时使用。以下情况需要留意：

- TUN 模式会跳过系统代理设置；
- 开启负载均衡时 TUN 会回退为单节点；
- 开启 TUN 时自动选路会暂停，由 TUN 接管全部流量。

TUN 启动失败时，进入 **网络诊断 → TUN 自检**，逐项检查平台、权限、内核、`wintun.dll` 与代理状态，并按修复建议处理；也可以点击「切换回系统代理」一键关闭 TUN 并切回系统代理（代理运行中会自动重启）。

### 3.4 局域网共享与入站认证

- **允许局域网连接**：开启后本地 SOCKS 入站监听 `0.0.0.0:<端口>`，同网段设备可把代理指向本机 IP；关闭时只监听 `127.0.0.1`。
- **入站认证**：为本地 SOCKS 入站启用用户名/密码认证。用户名不能包含空白字符，密码至少 6 位。

注意事项：

- 开启局域网共享后，请检查系统防火墙设置；建议同时开启入站认证，避免同网段设备无需密码即可使用代理。
- 入站认证只作用于本地 SOCKS 入站，不影响 TUN 入站。
- 修改端口、局域网开关或入站认证后，需要重启代理才会生效。

### 3.5 系统代理恢复与残留

- 正常停止代理或退出 FastV 时，系统代理与 PAC 配置会恢复为启动前的状态。
- 如果应用异常退出（崩溃、被强制结束）导致系统代理残留，可在 **网络诊断 → 网络救援** 中一键检测并修复（见 [9.3 网络救援](#93-网络救援)）。
- 覆盖安装或卸载旧版本后，如果仍残留 `fastv://` 协议注册、开机自启项或 PAC 文件，可在 **设置 → 系统集成 → 环境清理** 中检查并清理（见 [9.8 环境清理](#98-环境清理)）。

## 4. 节点管理

节点管理集中在 **服务器** 页。

### 4.1 列表、搜索与筛选

- 顶部统计显示全部节点数、启用数、当前节点与筛选结果数。
- 搜索框可按节点名称、标签、地址或订阅搜索。
- 支持按协议、标签、订阅筛选，以及按默认顺序、名称、延迟、收藏优先排序。
- 列表列包括节点、协议、地址、延迟、状态与操作；`手动` 标记表示通过分享链接导入的节点。

### 4.2 导入、编辑与分享

- **导入节点**：粘贴分享链接或 Base64 订阅内容，重复链接会自动跳过。
- **编辑节点**：点击行内编辑按钮打开节点编辑器，可修改名称、协议、服务器地址、端口、凭证、传输方式（RAW/TCP、WebSocket、gRPC、HTTPUpgrade、XHTTP）、安全层（TLS、REALITY）、SNI、Fingerprint、ALPN、Host/Path 等参数。
  - 编辑器底部提供 Xray outbound JSON 预览；高级用户可直接编辑 outbound JSON（留空则使用表单生成）。
  - 「保存」只保存修改；「保存并应用」会立即切换为当前节点，代理运行中会自动重启。
- **二维码**：查看节点分享二维码，弹窗内可复制分享链接。
- **启用 / 禁用**：禁用节点不会参与连接与自动选路。

### 4.3 收藏、标签与批量操作

- **收藏**：星标节点，可用于「收藏优先」排序与筛选。
- **标签**：点击节点标签或使用行内按钮编辑；可在批量操作中为多个节点统一设置标签（留空则清除标签）。
- **批量操作**：勾选多个节点后可批量启用、批量禁用、批量复制分享链接、设置标签、批量删除，并支持全选、取消全选、反选、清空选择。
- **排序**：默认顺序、按名称、按延迟、收藏优先。「默认顺序」保留节点原有的排列顺序。

### 4.4 延迟测速

- 行内「测速」与「测试当前列表」执行的是**真实链路 HTTP 延迟测速**：FastV 会临时启动一个 Xray 实例，通过各节点实际请求测试地址，可能耗时数秒。
- 延迟列优先显示真实链路结果；没有真实链路结果时回退显示 TCP 连通性结果，鼠标悬停可区分两种来源。
- 测试地址在 **设置 → 客户端设置 → 代理测试地址** 中配置，默认 `https://www.gstatic.com/generate_204`。
- 节点分组的自动测速可以单独设置测试 URL，留空时使用全局测试地址。

### 4.5 节点分组

在服务器页顶部「分组」栏管理分组：

| 分组类型 | 行为 |
|---|---|
| 手动 | 仅用于快速筛选与切换节点，不会自动测速 |
| 自动测速 | 按设置间隔测试分组内节点，并自动切换到延迟最低的节点 |

- 分组只保存节点引用，删除分组不会删除节点。
- 自动测速间隔为 0 表示不自动测速；大于 0 时必须为 5–1440 分钟。
- 「测速并选择最优」会立即测试分组内全部节点并切换到最快节点。

### 4.6 自动选路、故障切换与负载均衡

以上能力在 **设置 → 智能选路** 中配置：

- **自动选择最优节点**：按选路间隔（1–1440 分钟，默认 10 分钟）对所有启用节点做 URL 延迟测速；只有新节点比当前节点快出「切换容差」（0–5000 毫秒，默认 80 毫秒）才会切换，避免频繁抖动。
- **故障自动切换**：代理运行中每 30 秒做一次健康检查，连续 2 次失败后自动切换到延迟最低的可用节点。
- **负载均衡**：把全部启用节点交给 Xray 的 balancer，每条连接按策略选择节点。
  - 策略：延迟优先（leastPing，默认）、负载优先（leastLoad）、轮询（roundRobin）。
  - 需要至少 2 个启用节点，不足 2 个时自动回退单节点。
  - 负载均衡与自动选路/故障切换互斥：启用负载均衡后，代理启动时会暂停自动选路与故障切换。
  - TUN 模式暂不支持多出站负载均衡，启动时会回退单节点并写入内核日志。
- 以上设置保存后需要重启代理生效；实际切换与回退原因会写入日志页。

## 5. 路由与规则

路由规则决定「规则分流」模式下每条流量走代理、直连还是拦截，位于 **路由** 页。

### 5.1 匹配顺序

- 规则从上到下匹配，命中后停止，不再继续匹配后续规则。
- 未命中任何规则的流量按当前代理模式处理（规则模式默认走代理）。
- 用户规则排在规则集订阅展开的规则之前。
- 规则支持启用/禁用与上移/下移调整顺序；代理运行中修改规则会自动重启内核使配置生效。

### 5.2 规则类型与动作

| 规则类型 | 说明与示例 |
|---|---|
| 域名后缀 | `example.com` 匹配其全部子域名 |
| 域名关键字 | 匹配域名中包含的关键字 |
| 域名正则 | 使用 Xray `regexp:` 规则 |
| IP / CIDR | 例如 `10.0.0.0/8`，可逗号分隔多个 |
| GeoSite | 例如 `category-ads-all`、`cn` |
| GeoIP | 例如 `private`、`cn` |
| 端口 | 例如 `80,443,1000-2000` |
| 网络协议 | `tcp`、`udp` 或 `tcp,udp` |
| 进程名 | Windows 进程名，例如 `chrome.exe,Telegram.exe`（逗号或换行分隔） |

每条规则的动作：

- **走代理**：流量经当前节点转发；
- **直连**：流量不经过代理；
- **拦截**：直接阻断该流量。

### 5.3 规则预设、导入导出与排序

- **规则预设**：内置「私有网络直连」「广告拦截」「中国大陆域名直连」「中国大陆 IP 直连」「绕过中国大陆」等组合，应用后会替换当前全部规则，应用后仍可继续编辑。
- **恢复默认**：恢复内置的默认规则（私有网络直连、广告域名拦截、中国大陆 IP 直连、中国大陆域名直连）。
- **导出 JSON / 导入 JSON**：把当前规则导出为 JSON 备份，或从 JSON 文件导入并整体覆盖当前规则。

### 5.4 规则集订阅

规则集订阅把远程域名/IP 列表定时下载并展开为路由规则，适合维护广告拦截、常见分流列表。

- 添加时填写：名称、订阅地址（`http://` 或 `https://`）、规则类型（域名 / IP / 混合）、动作（代理 / 直连 / 拦截）、是否自动更新、更新间隔。
- 更新间隔默认为 360 分钟，可选 15–1440 分钟；开启自动更新后按间隔刷新。
- 支持的内容格式：
  - 纯文本域名（每行一个）与通配写法（`.example.com`、`*.example.com`）；
  - hosts 写法（`0.0.0.0 example.com`、`:: example.com`）；
  - Adblock 域名规则（`||example.com^`）；
  - Clash / Mihomo 前缀（`DOMAIN-SUFFIX,example.com`、`DOMAIN,example.com`、`IP-CIDR,1.2.3.0/24`）；
  - 纯 IP 与 CIDR。
- 下载限制：20 秒超时、最大 4 MB；更新成功后规则才会展开生效，更新失败时保留上一次成功下载的规则。
- 规则集在启用时展开为路由规则，排在用户规则之后；可点击「全部更新」刷新全部已启用的规则集。

### 5.5 规则调试器

规则调试器用于回答「这条流量到底命中哪条规则」，位于路由页：

1. 在「调试目标」中输入域名、IP、进程名、端口或协议，或选择匹配类型（自动识别 / 域名 / IP / 进程 / 端口 / 协议）。
2. 点击「调试」。
3. 结果会显示命中的规则、动作、出站，以及规则来源（用户规则 / 规则集 / 默认出站）。

说明：

- 调试在本地离线计算，不会启动或重启内核；代理运行中也可以安全使用。
- GeoIP / GeoSite 规则需要 Xray 在运行时结合 Geo 数据判定，调试器会将其标注为「需运行时判定」，并在「被跳过、需运行时判定的规则」中列出。

## 6. 订阅管理

### 6.1 添加、更新与删除

- **添加**：填写名称（可选）与订阅地址，添加成功后立即完成首次解析。订阅地址必须是 `http://` 或 `https://`。
- **更新**：单个订阅点击「更新」，或使用「全部更新」批量刷新。更新会保留节点 ID 与启用状态，已删除的节点会同步移除。
- **查看节点**：订阅卡片上的「节点」按钮列出该订阅解析出的节点，可直接「设为当前」。
- **删除**：删除订阅会同时删除其解析出的节点，操作前会确认。
- **二维码**：订阅二维码包含私有令牌，弹窗只显示二维码图片，不显示或复制文本链接。

### 6.2 套餐流量与到期信息

订阅响应头中的 `Subscription-Userinfo` 会被解析为上传量、下载量、总量与到期时间：

- 订阅卡片显示已用 / 总量进度、上传与下载量、用量更新时间；
- 顶部统计显示启用订阅数、节点数、最近到期天数与过期订阅数；
- 概览页同步显示套餐流量与到期提醒；
- 订阅端未提供的信息显示为「未提供」或「用量未知」，不影响节点使用。

### 6.3 自动更新

自动更新分为全局与订阅两级：

- **全局**：设置 → 客户端设置 → 订阅更新，可配置「自动更新订阅」开关与「更新间隔」（15–1440 分钟，默认 360 分钟）。开启后应用启动后会按间隔检查订阅。
- **订阅独立设置**：每个订阅卡片上的「设置」可以单独控制：
  - 是否自动更新（关闭后只能手动更新）；
  - 更新间隔（「跟随全局」或 15–1440 分钟的独立间隔）；
  - 自定义 User-Agent（最长 200 个字符，不能包含换行；留空使用默认 `FastV/<版本>`）。

### 6.4 更新失败与代理重试

- 默认开启「订阅更新失败时通过本地代理重试」：直连拉取失败且本地代理正在运行时，FastV 会自动通过本地代理重试一次。
- 如果直连与代理重试都失败，错误信息会明确提示「直连与代理重试均失败」，便于区分是网络问题还是订阅地址问题。
- 代理未运行时不会代理重试；可在设置中关闭该开关。
- 单个订阅更新失败不会影响其他订阅与已有节点。

## 7. 备份与恢复

备份与恢复位于 **设置 → 备份与恢复**。请注意：备份文件包含节点凭据（UUID、密码等），请妥善保管，不要上传到公开位置。

### 7.1 本地导出与导入

- **导出备份**：生成 `fastv-backup-YYYYMMDD-HHmm.json` 并通过浏览器下载保存，内容包含完整配置（设置、订阅、节点、路由规则、当前节点等）。
- **导入备份**：选择本地 JSON 备份文件进行恢复。导入会覆盖当前全部配置；导入成功后代理不会自动重启，需要手动重启代理后生效。
- 导入前会校验备份格式，文件无效或损坏时返回中文错误，且不会改动当前配置。

### 7.2 WebDAV 云备份

- 需要填写：服务器地址（必须以 `http://` 或 `https://` 开头）、用户名、密码/应用专用密码、远端备份路径（默认 `/FastV/fastv-backup.json`）。
- 认证方式为 HTTP Basic；建议使用应用专用密码并优先使用 HTTPS。
- 操作流程：先点击「保存设置」，再执行「测试连接」「上传到云端」「从云端恢复」。修改服务器地址、账号或路径后，需要重新保存设置。
- 「从云端恢复」会使用云端备份覆盖当前全部配置（设置、订阅、节点与路由规则），且无法撤销，因此会先弹出确认。
- 远端备份路径的父目录不存在时会自动创建；单次上传/下载上限为 16 MB，测试连接超时约 30 秒，上传/恢复超时约 120 秒。
- 错误信息会包含 HTTP 状态码，且不会回显密码。

### 7.3 配置快照与回滚

配置快照保存在本机，适合在调整设置或规则前留一个可回滚的还原点。

| 操作 | 说明 |
|---|---|
| 创建快照 | 输入名称（可留空使用默认名称），保存当前完整配置 |
| 回滚 | 用快照内容覆盖当前全部配置；回滚前 FastV 会自动创建一个「回滚前快照」，因此回滚本身可以撤销 |
| 删除 | 删除指定快照，删除后无法恢复 |
| 导出 | 通过系统保存对话框把快照导出为 JSON 文件（与本地备份格式兼容） |
| 导入快照 | 从本地 JSON 备份文件导入为一个新快照 |

限制与提示：

- 本地最多保留 20 个快照，超出后自动删除最旧的快照。
- 回滚完成会提示「请重启代理生效」。
- 快照文件保存在 `<数据目录>/snapshots/`，每个快照上限 8 MB；损坏的快照文件会在列表中跳过。

**备份与快照的区别**：备份（本地 JSON / WebDAV）是可带到其他设备或云端的配置文件；快照是本机自动管理的还原点，最多 20 个，回滚前还会自动留一份安全快照。详见 [FAQ Q17](product/FAQ.md#q17-备份和配置快照有什么区别)。

## 8. 安全与隐私

### 8.1 本地数据与敏感配置加密

- 数据目录权限为仅当前用户可访问（目录 `0700`，`data.json` 为 `0600`）。
- **Windows**：WebDAV 密码与入站认证密码写入 `data.json` 时会使用 Windows DPAPI 加密，密文以 `enc:v1:` 前缀标识，并绑定当前 Windows 用户与机器。另一个 Windows 用户、另一台机器或直接复制出去的 `data.json` 都无法解密。
- 如果密文无法解密（例如更换了 Windows 用户或机器），FastV 会清空该密码字段并继续加载其他配置，不会把密文当作密码使用；重新填写并保存即可。
- 旧版本写入的明文密码仍然可以正常读取，并在下一次保存时自动转为加密存储。
- **macOS / Linux**：当前没有 DPAPI 等价后端，这两个字段以明文保存在仅当前用户可读的 `data.json` 中，请确保系统账户与磁盘安全。
- 备份文件与导出的快照使用内存中的明文配置，因此其中包含明文凭据；请妥善保管。

### 8.2 备份文件与快照

- 本地备份、WebDAV 备份、导出的快照 JSON 都包含节点凭据与密码，应按敏感文件管理。
- 从云端恢复、导入备份、回滚快照都会覆盖当前全部配置，操作前请确认或在操作后保留安全快照。
- 上传 WebDAV 前建议确认服务器可信、使用 HTTPS 与应用专用密码。

### 8.3 入站认证与局域网

- 开启「允许局域网连接」会把本地入站暴露到局域网，请确认防火墙配置，并建议同时开启入站认证。
- 入站认证密码至少 6 位，用户名不能包含空白字符；修改后需要重启代理生效。

### 8.4 诊断报告脱敏

- 一键导出的诊断报告 ZIP 默认脱敏：不包含订阅 URL、密码和节点凭据。
- 报告包含：构建/平台信息、设置摘要（白名单字段与计数）、最近的脱敏运行日志、自检结果。
- 分享报告前仍建议快速浏览一遍内容。

### 8.5 数据与文件位置

数据目录可在 **设置 → 应用信息 → 数据目录** 查看，默认位置：

| 平台 | 默认数据目录 |
|---|---|
| Windows | `%APPDATA%\FastV`（如 `C:\Users\<用户名>\AppData\Roaming\FastV`） |
| macOS | `~/Library/Application Support/FastV` |
| Linux | `~/.config/FastV` |

若首选目录不可写，FastV 会依次回退到系统缓存目录或启动目录下的 `.fastv-data`。也可以用环境变量 `FASTV_DATA_DIR` 指定自定义数据目录。

数据目录内的主要内容：

| 路径 | 内容 |
|---|---|
| `data.json` | 设置、订阅、节点、路由规则、当前节点、历史统计等 |
| `logs/fastv.log` | 运行日志（5 MB 轮转，保留 3 个文件） |
| `snapshots/` | 配置快照 |
| `pac/fastv.pac` | PAC 模式下生成的脚本 |
| `cores/xray/` | 自动下载的 Xray 内核与 `wintun.dll` |
| `updates/` | 应用内更新下载与解压的安装包 |

## 9. 诊断与排障

**网络诊断** 页集中了网络与运行环境的检查工具。

### 9.1 网络诊断

- 「直连出口」与「代理出口」分别检测公网 IP（IPv4 / IPv6）、国家/地区/城市/时区、ASN/运营商/ISP、Cloudflare 边缘节点、TLS 版本、WARP 状态。
- 「网络质量」检测延迟、抖动与 5 MB 下载速度；可勾选「包含下载测速」。
- 对比结果会显示出口 IP 是否切换（「出口 IP 已切换」/「出口 IP 相同」）。
- 「延迟历史」保存最近若干次 URL 测速结果，支持刷新与清除；清除历史会同时清除流量与延迟历史，且不可撤销（不影响订阅、节点与设置）。
- 检测接口带有备用线路与自动重试，Cloudflare trace 不可用时会切换其他检测方式。

### 9.2 一键自检

在 **网络诊断 → 一键自检** 中点击「开始自检」，FastV 会逐项检查并给出通过/警告/失败结论：

1. Xray-core 安装
2. Xray 配置校验
3. 本地代理端口
4. 统计 / API 端口
5. TUN 模式权限
6. Windows 系统代理
7. 网络测试地址
8. Geo 数据文件
9. 数据目录写入
10. 订阅状态

失败项通常附带修复建议；修复后可重新自检。

### 9.3 网络救援

「网络救援」用于处理「用不了网 / 关掉 FastV 后上不了网」的常见原因：

- 检测项：系统代理残留、系统代理地址与本地入站不一致、WinHTTP 代理残留、本地入站端口被占用（代理未运行时检查）、代理核心异常等。
- 「一键修复」的行为：
  - 代理未运行：重置系统代理（同时尽力清理 WinHTTP 代理）、刷新 DNS 缓存；
  - 代理正在运行：刷新 DNS 缓存并重启本地代理（此时系统代理仍指向有效的本地入站，不做重置）。
- 修复结果会列出「已修复」与「未修复」项；仍失败时可按提示手动处理。

### 9.4 DNS 审计

「DNS 审计」对比系统 DNS 与 Xray DNS 配置，并向每个解析器发送真实 A 记录查询：

- 展示系统 DNS、Xray DNS、解析探针结果（服务器、查询域名、解析 IP、延迟、错误）；
- 给出风险提示，例如使用明文 DNS、系统 DNS 与 Xray DNS 不一致、系统代理模式下可能绕过代理导致泄露或劫持等。

说明：系统 DNS 的读取目前仅 Windows 支持；其他平台会跳过对应检查或给出提示。

### 9.5 TUN 自检与回退

「TUN 自检」逐项检查 TUN 依赖并给出修复建议：

- 平台是否支持 TUN；
- TUN 设置是否开启；
- 是否具有管理员权限；
- Xray 内核是否安装；
- `wintun.dll` 是否位于内核同目录；
- 代理是否运行、TUN 是否已生效。

存在失败项时可直接点击「切换回系统代理」：FastV 会关闭 TUN、切换到系统代理并保存设置；若代理正在运行会自动重启代理使模式生效。

### 9.6 诊断报告

点击「导出诊断报告」会在数据目录生成 `diagnostics-report-*.zip`，界面会显示报告路径。报告包含：

- `summary.json`：构建与平台信息、脱敏的设置摘要、记录计数、代理状态、自检摘要；
- `logs.txt`：最近的代理日志（最多 200 条，URL、凭据与 UUID 已脱敏）；
- `selfcheck.json`：完整自检结果（同样脱敏，导出时可用才生成）。

反馈问题时可把该 ZIP 附在 issue 中，能显著减少来回确认环境的时间。

### 9.7 运行日志

**日志** 页实时显示 Xray 的 stdout / stderr：

- 支持关键词搜索、等级筛选（debug/info/warning/error）、暂停/继续接收、自动滚动；
- 支持复制当前筛选日志、复制全部日志、导出当前筛选结果为 `.log` 文件、清空；
- 内存中最多保留 1500 条日志，避免无限增长。

此外，FastV 会把应用运行日志持久化到文件，便于崩溃后排查：

- 路径：`<数据目录>/logs/fastv.log`（Windows 默认 `%APPDATA%\FastV\logs\fastv.log`）；
- 每行格式：`时间 [级别] [来源] 消息`；
- 单个文件最大 5 MB，轮转为 `fastv.log`、`fastv.1.log`、`fastv.2.log`，最多保留 3 个文件；
- 启动、退出、崩溃（含堆栈）以及内核/代理日志都会写入该文件。

### 9.8 环境清理

**设置 → 系统集成 → 环境清理** 用于清理卸载或覆盖安装后的系统残留：

- 检查/清理 `fastv://` 协议注册、开机自启项与 PAC 文件；
- 清理只移除上述系统集成项，**不会删除**订阅、节点与设置等用户数据；
- 面板会显示数据目录路径；需要彻底清理时再手动删除数据目录（见 [11.5 彻底卸载](#115-彻底卸载)）。
- 该能力面向 Windows；其他平台上不支持的平台检查项会以提示形式说明无法检测。

## 10. 个性化、托盘与快捷键

### 10.1 主题、强调色、布局与语言

位于 **设置 → 客户端设置**：

- **界面主题**：深色、浅色、跟随系统。默认浅色；选择后立即预览，保存后应用到下次启动。
- **强调色**：天空蓝（默认）、紫罗兰、翡翠绿、琥珀橙、玫瑰红，用于主按钮、开关、选中态与焦点环。
- **导航布局**：侧边模式（保留左侧导航）或底栏模式（液态玻璃底栏，默认）。底栏模式下可调整「底栏透明度」（5–90，默认 28）。
- **界面语言**：简体中文（默认）或 English。切换后立即生效，保存后持久化。

### 10.2 托盘与窗口行为

- **系统托盘**（Windows）：托盘菜单提供显示/隐藏主窗口、启动/停止/重启代理、代理模式子菜单（规则/全局/直连）、节点子菜单、检查更新与退出。
- **托盘状态颜色**：绿色＝代理运行中，琥珀色＝启动中/停止中，红色＝代理异常，蓝色＝代理未启动。鼠标悬停可看到当前状态与代理模式。
- **窗口行为**：可开启「关闭窗口时最小化到托盘」与「最小化时隐藏到托盘」。两者都依赖系统托盘；托盘不可用时，关闭窗口仍会退出应用。

### 10.3 全局快捷键

位于 **设置 → 系统集成 → 全局快捷键**（Windows）：

| 默认快捷键 | 动作 |
|---|---|
| `Ctrl+Shift+F` | 启动 / 停止代理 |
| `Ctrl+Shift+M` | 切换代理模式（规则 → 全局 → 直连） |
| `Ctrl+Shift+N` | 切换到下一个启用节点 |

- 点击「录制」后按下组合键即可修改；组合键必须包含 `Ctrl`、`Alt`、`Shift`、`Win` 中至少一个修饰键，主键仅支持 A–Z、0–9 与 F1–F24。
- 修改开关或组合后需要保存设置才会生效；快捷键重复或格式错误会提示。
- 快捷键被其他程序占用时会注册失败，可在日志页查看原因。
- 如果启动 FastV 时快捷键开关处于关闭状态，重新开启后需要重启应用才会重新注册。

### 10.4 深链接 `fastv://`

Windows 上 FastV 会注册 `fastv://` 协议；其他平台暂未注册系统协议处理程序，但命令行参数仍然有效。

支持的深链接形式：

```text
fastv://import?url=<订阅地址>
fastv://node?link=<节点分享链接>
```

示例：

- 导入订阅：`fastv://import?url=https%3A%2F%2Fexample.com%2Fsub`
- 导入节点：`fastv://node?link=vless%3A%2F%2F...`

导入成功后界面会弹出提示，可跳转订阅页查看；失败时会显示原因。

### 10.5 命令行参数

FastV 会从命令行参数中识别深链接与原始分享链接，其他参数（程序路径、普通文件路径）会被忽略：

```powershell
# 通过命令行导入订阅
Fast-V.exe "fastv://import?url=https://example.com/sub"

# 直接传入分享链接导入节点
Fast-V.exe "vmess://..."

# 一次传入多个链接
Fast-V.exe "fastv://node?link=vless://..." "fastv://import?url=https://example.com/sub"
```

- 如果 FastV 已在运行，启动新实例会把窗口带到前台并导入链接（同一次命令中的重复链接只导入一次）。
- Windows 下路径与参数建议使用引号包裹，避免空格与 `:` 截断。

### 10.6 应用信息

**设置 → 应用信息** 显示应用版本、界面版本与数据目录路径，反馈问题时可一并提供。

## 11. 更新与卸载

### 11.1 应用内更新（Windows）

位于 **设置 → 系统集成 → 应用更新**：

- 可开启「启动时自动检查更新」；也可点击「立即检查更新」手动检查。
- 发现新版本后可「下载更新」，下载完成后点击「立即重启并安装」，FastV 会退出、替换程序文件并自动重新启动。
- 如果发布版本没有提供适用于 Windows 的安装包，界面会提示打开发布页面手动下载。
- 代理正在运行时会提示安装过程会短暂中断网络，建议先停止代理。
- 应用内自动更新当前仅支持 Windows；macOS / Linux 请到 Releases 页面手动下载替换。

### 11.2 内核与 GeoData 更新

- **设置 → 内核设置**：查看当前/最新 Xray-core 版本，检查更新、下载最新版；可开启「自动检查并下载 Xray 内核更新」。
- 「GeoData 资源」区域可刷新状态、下载/更新 `geoip.dat` 与 `geosite.dat`；路由中的 GeoIP/GeoSite 规则依赖这些资源。
- 内核或 GeoData 更新后，重启代理生效。

### 11.3 停止与退出

- 停止代理会释放本地端口、恢复系统代理/PAC 配置并清理 TUN 路由。
- 关闭窗口默认退出应用；如开启了「关闭窗口时最小化到托盘」，请从托盘菜单选择「退出」。
- 退出时会清理内核进程，避免残留 `xray.exe`。

### 11.4 卸载

**Windows**

1. 建议先停止代理，并从托盘菜单正常退出 FastV。
2. 打开「设置 → 应用 → 已安装的应用」，找到 FastV 选择卸载；或运行安装目录下的 `uninstall.exe`。
3. 卸载程序会删除程序文件、快捷方式与卸载注册项，**不会删除** `%APPDATA%\FastV` 下的用户数据。

**macOS**

1. 退出 FastV，把 `FastV.app` 从「应用程序」移到废纸篓。
2. 用户数据 `~/Library/Application Support/FastV` 会保留，需要时手动删除。

**Linux**

- deb 安装：`sudo apt remove fastv`。
- tar.gz 便携包：删除解压出的文件与可选的桌面入口文件。
- 用户数据 `~/.config/FastV` 会保留，需要时手动删除。

### 11.5 彻底卸载

如需完全清理：

1. 停止代理并退出 FastV。
2. 按 [11.4](#114-卸载) 卸载程序。
3. 打开 **设置 → 系统集成 → 环境清理**，检查并清理 `fastv://` 协议注册、开机自启项与 PAC 文件（此步骤需在删除程序前完成）。
4. 删除数据目录（默认 `%APPDATA%\FastV`；路径可在删除前从「应用信息 → 数据目录」确认）。
5. 如需一并清理云端备份，登录 WebDAV 服务器删除对应备份文件。

### 11.6 数据迁移

- 直接把整个数据目录复制到新机器相同位置即可带走订阅、节点、设置与快照；建议迁移前先退出 FastV。
- 也可以使用「导出备份 / WebDAV 上传」后再在新机器导入。
- 注意：Windows DPAPI 加密的 WebDAV 密码与入站密码**无法跨机器或跨 Windows 用户解密**，迁移后这些字段会被清空，需要重新填写；其余配置不受影响。

### 11.x 流量悬浮球（可选）

- 入口：设置 → 系统集成 → 「显示流量悬浮球」，默认关闭；打开后保存设置立即出现。
- 形态：桌面右下角的圆形悬浮球，始终置顶，显示实时下行/上行速率（如 `↓ 6.7M ↑ 288B`）与最近约 30 秒的流量波形：
  - 绿色呼吸环 = 代理运行中；琥珀色 = 启动/停止中；红色 = 代理异常；灰色「未连接」= 代理未运行。
- 操作：按住拖动可移动位置；单击悬浮球回到 FastV 主界面。
- 关闭：在设置中关闭开关并保存；悬浮球窗口会被销毁，不会占用 WebView 资源。
- 平台：当前主要面向 Windows 桌面；其他平台窗口行为取决于 Wails 运行时支持。

## 11.y Android 预览版

- 安装：下载 `FastV-<version>-android-arm64.apk`，允许「安装未知来源应用」后安装；当前为 debug 签名预览包，适合测试。
- 已支持：订阅添加/更新、节点与分组管理、路由规则与规则集、备份/快照、导入导出、主题与语言（移动端自动切换为单列/底部导航布局）。
- 暂不支持：系统代理、TUN/VPN、悬浮球、托盘、全局快捷键、应用内更新；在 Android 上点击「启动代理」会提示该版本暂不支持。
- 数据位置：应用私有目录（系统设置中清除数据会重置 FastV 配置）。
- 卸载：长按图标卸载即可；如需清理数据，先在系统设置中清除应用数据。

## 12. 常见问题

完整的问题排查手册见 [常见问题 FAQ](product/FAQ.md)，覆盖无法上网、TUN 失败、核心崩溃、订阅失败、规则不生效、测速不准、WebDAV 失败、PAC 模式、开机自启与权限、端口占用、日志位置、诊断报告、macOS 未签名、Linux 依赖、配置文件迁移、备份与快照、数据加密与快捷键等主题。

高频问题速查：

- 启动代理后仍无法上网：先运行 **网络诊断 → 网络救援** 检测系统代理残留与端口占用。
- TUN 启动失败：运行 **网络诊断 → TUN 自检**，检查管理员权限与 `wintun.dll`。
- 订阅更新失败：检查订阅地址与网络，并确认「订阅更新失败时通过本地代理重试」已开启。
- 规则不生效：用 **路由 → 规则调试器** 查询实际命中的规则。
- 需要反馈问题：**网络诊断 → 导出诊断报告**，把脱敏 ZIP 附到 issue。
