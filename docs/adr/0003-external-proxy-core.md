# ADR-0003: 代理协议由外部内核执行

- 状态：Accepted
- 日期：2026-10-31

## 背景

VMess、VLESS、Trojan、Shadowsocks、TLS、Reality、QUIC 等协议实现复杂且持续演进。自行实现协议栈会带来巨大的安全、兼容性和维护成本。

## 决策

FastV 不实现代理协议，使用外部代理内核：

- 第一版使用 Xray-core。
- 后续增加 sing-box，覆盖 Hysteria2、TUIC、WireGuard 和 TUN。
- Go 后端通过 `os/exec` 启动内核，使用 Job Object 管理进程树。
- Go 负责配置生成、校验、日志采集和生命周期管理。

## 后果

### 正面影响

- 不承担协议实现风险。
- 可直接复用成熟协议实现。
- 配置生成与核心版本可以独立升级。

### 负面影响

- 需要管理外部二进制和版本兼容。
- 配置 schema 随内核版本变化。
- 安装包增大，可能需要处理杀毒软件误报。

## 备选方案

| 方案 | 优点 | 缺点 | 未采用原因 |
|---|---|---|---|
| 自研协议栈 | 单二进制、完全可控 | 成本极高、风险大 | 不现实 |
| 嵌入 Xray 库 | 单进程 | API 不稳定、升级复杂 | 先采用进程隔离 |
| sing-box 单内核 | 协议覆盖广 | Xray 特性兼容性需验证 | 作为第二阶段方案 |
