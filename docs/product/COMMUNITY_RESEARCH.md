## 二、FastV 已对齐/领先的能力

- 真实链路 URL 延迟测速、自动选优、故障切换、负载均衡（对应第 7 类）
- 系统代理 / TUN（Windows）、节点分组与自动测速分组
- 规则编辑、规则集订阅、配置覆写
- 订阅独立自动更新、WebDAV 备份、多语言、多平台构建
- 深链接导入、全局快捷键、自定义强调色

## 三、本轮新增（直接回应社区问题）

| 社区问题 | FastV 改进 |
|---|---|
| 第 1 类：核心崩溃/卡死 | **核心看门狗**：核心异常退出后 1s/2s/4s 指数退避自动重启，最多连续 3 次，运行满 60s 重置；用户主动停止优先，不误重启；日志与状态事件可见 |
| 第 3 类：无法上网/代理残留 | **一键网络救援**：检测系统代理残留、系统代理地址与本地入站不一致、WinHTTP 代理残留、本地端口被占用、核心异常；一键重置系统代理、清理 WinHTTP、刷新 DNS、必要时重启内核 |
| 第 4 类：订阅更新失败 | **订阅更新代理重试**：直连失败且代理运行时自动通过本地代理重试一次，错误信息区分“直连与代理重试均失败” |
| 第 2/5 类：规则与 TUN 排查困难 | **规则调试器**：输入域名/IP/进程/端口/协议，离线给出命中规则、动作、出站与默认策略；GeoIP/GeoSite 规则标注“需运行时判定”；支持规则集来源 |
| 支持求助信息缺失 | **诊断报告一键导出**：脱敏 ZIP（设置白名单 + 计数、脱敏日志、自检结果），可直接附到 issue |
| 第 9 类：用户反馈困难 | 诊断报告包含环境、状态与失败检查项 |

## 四、FastV 的差异化创新点

1. **面向“故障恢复”的闭环**：检测 → 解释 → 一键修复（救援服务 + 规则调试器 + 看门狗 + 报告导出），同类客户端多数只提供日志。
2. **规则调试器**：把“分流到底走哪条规则”从日志排查变成可查询结果，并区分用户规则/规则集/默认策略。
3. **看门狗与用户操作优先级**：崩溃自动重启但绝不覆盖用户主动停止；稳定运行后重置计数，避免无限重启。
4. **诊断报告脱敏导出**：默认不泄露订阅 URL、密码、节点地址，降低用户求助时的隐私风险。
5. **订阅粒度控制**：每个订阅独立间隔/UA/代理重试，而多数同类只有全局开关。
6. **多平台一致构建**：Windows/macOS/Linux 同一套 UI 与功能（Windows 专属能力除外）。

## 五、后续路线（按社区热度）

1. **DNS 泄露/污染检测**（第 6 类）：检测直连 DNS、系统 DNS、DoH 配置建议。
2. **TUN 自检与回退向导**（第 2 类）：TUN 启动失败时解释原因并建议切回系统代理。
3. **PAC 模式**（第 8 类）：生成 PAC 文件并设置系统代理 AutoConfigURL。
4. **卸载残留清理 / 自启与权限体检**（第 9 类）。
5. **托盘状态可视化**（第 10 类）：按模式/状态切换托盘图标颜色。
6. **配置快照与回滚**：自动保存配置版本，一键回到之前可用状态。
